# Security

## Reporting a vulnerability

Report it privately through
[GitHub's reporting form](https://github.com/clintonium-119/es-de-overlay/security/advisories/new).
Include the app version, steps to reproduce and what an attacker could do. Please don't post
exploit details in a public issue.

If you can't use the form, open an issue that says you found a security problem, without the
details or a way to exploit it, and you'll be asked for them privately.

## Supported versions

Fixes go into the latest release only.

## What the app can access and when it goes online

[Privacy and safety](https://clintonium-119.github.io/es-de-overlay/privacy.html) lists every
permission the app asks for, what it uses each one for, and when it goes online.
